## 2024-03-20 - Inline Form Validation
**Learning:** Using a blocking `alert()` for form validation is terrible for UX and accessibility. Screen readers don't handle them gracefully and they interrupt user flow. Replacing them with an inline error div with `role="alert"`, adding `aria-invalid="true"`, applying visual cues (like a red border), and programmatically focusing the first invalid input drastically improves the experience for all users.
**Action:** When implementing form validation, avoid `alert()`. Create a dedicated error container with `role="alert"`, apply `aria-invalid` to offending inputs, visually distinguish them (e.g., via inline styles `borderColor = '#c04040'` if custom CSS is disallowed), and explicitly set focus to the first invalid field. Clear previous error states before re-evaluating.
