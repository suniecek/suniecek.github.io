## 2024-03-18 - Keyboard Accessibility for Div Buttons
**Learning:** The codebase mimics a desktop OS using `div` elements for interactive controls (`.icon`, `.start-button`, `.taskbar-button`, `.window-button`). Applying static ARIA attributes (`role`, `tabindex`, `aria-label`) directly to these elements enables basic screen reader support. However, mapping Enter/Space to click events via a global `keydown` listener is overly broad and intercepts inputs across the document.
**Action:** When implementing keyboard accessibility on custom `div`-based buttons, attach specific `keydown` listeners directly to the dynamically created elements (e.g., `button.addEventListener('keydown', ...)` in `script.js`) rather than relying on a global document listener to avoid unintended side effects and more closely mirror native button behavior.
