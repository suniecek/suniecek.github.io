## 2024-10-24 - Replaced Blocking Alert with Inline Validation in Vanilla JS
**Learning:** Using `alert()` for form validation blocks the main thread and provides a poor, inaccessible experience compared to modern web standards. By replacing it with dynamic inline validation (an error div with `role="alert"`) and programmatically setting `aria-invalid="true"`, we improve accessibility and provide smoother user interaction. Explicitly managing visual state through DOM styling (border color) without adding custom CSS aligns with the strict 'no custom CSS' constraints while still effectively communicating error states visually.
**Action:** When validating forms in this vanilla JS environment under constraints that prevent custom CSS, implement inline validation by generating elements with `role="alert"` and updating `aria-invalid` and inline styles (e.g., `borderColor`) directly on the target inputs. Ensure previous error states are cleared before re-evaluating inputs to prevent stale error indicators.
