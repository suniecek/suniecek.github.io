## 2025-05-06 - ARIA Labels for Icon Buttons and Inputs
**Learning:** In highly customized, retro-style interfaces that rely heavily on visual cues (like placeholder text instead of labels, or icon-only buttons for controls), native inputs and buttons often end up completely invisible to screen readers. Specifically, `<input type="color">` pickers and game control buttons using raw arrow symbols (↑, ↓, ←, →) require explicit `aria-label` attributes to be accessible, as their visual presentation offers no programmatic text alternative.
**Action:** Always scan custom form inputs (especially color pickers) and icon-only buttons across the application to ensure they have descriptive `aria-label` attributes injected either statically in HTML or, if dynamically generated, via JavaScript.
