## 2024-05-15 - Replace blocking alert() with accessible inline validation
**Learning:** Using blocking `alert()` dialogs for form validation is a poor UX pattern that breaks the flow and is inaccessible. Screen readers might not always handle them gracefully, and they pull the user out of the context of the form. Replacing them with an inline error message using `role="alert"` ensures screen readers announce the error immediately, while `aria-invalid="true"` explicitly marks the problematic fields. Programmatically focusing the first invalid input directly guides the user to correct the error.
**Action:** When implementing form validation, avoid `alert()`. Instead, create a dedicated error container with `role="alert"`, apply `aria-invalid="true"` and visual error indicators (like a red border) to invalid inputs, and shift focus to the first invalid field to guide correction.
