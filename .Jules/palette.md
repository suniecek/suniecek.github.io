## 2026-01-10 - Replacing Blocking Alerts with Inline Validation
**Learning:** Native `alert()` dialogs in browser applications severely disrupt user experience and accessibility, as they freeze the interface and provide no context directly associated with the input fields. Screen readers may read the alert but fail to guide the user back to the problem area.
**Action:** When validating forms (like the Guestbook), replace `alert()` calls with inline error messages using `role="alert"` for immediate screen reader announcement. Visually indicate errors using inline styles (e.g., `element.style.borderColor = '#c04040'`) since custom classes shouldn't be added, apply `aria-invalid="true"`, and programmatically focus the first invalid input to guide the user naturally to the fix. Always clear previous error states first to prevent stale error indicators on subsequent attempts.
