## 2024-05-24 - Accessible Inline Validation Replaces Blocking Alerts
**Learning:** Using `alert()` for form validation is a poor UX pattern because it is blocking, inaccessible to many assistive technologies, and interrupts the user flow abruptly. When replacing it, it's critical to use an inline element with `role="alert"` so screen readers immediately announce the error. Adding `aria-invalid="true"` and styling the fields (e.g., `#c04040` borders) provides strong visual and structural feedback without disrupting the experience.
**Action:** Always replace `alert()` validations with inline error elements. Ensure these elements have `role="alert"`, the corresponding inputs get `aria-invalid="true"`, and any visual error state relies on standard colors from the palette to remain consistent. Remember to remove these error states upon successful submission or interaction.
