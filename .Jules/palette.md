## 2024-05-18 - Non-blocking Inline Validation for Vanilla JS Windows
**Learning:** Native `alert()` calls for form validation (e.g., in custom window implementations like Guestbook) are inaccessible and block interaction. When limited to vanilla JS and existing CSS, applying inline styling (e.g., `#c04040` red borders) and semantic accessibility attributes (`role="alert"`, `aria-invalid`) via DOM manipulation provides a superior, non-disruptive user experience.
**Action:** When migrating away from `alert()` validations in custom JS windows, dynamically insert a text node with `role="alert"` and apply `aria-invalid="true"` alongside explicit border styling to the offending inputs. Always remember to clear these states (e.g., `element.style.border = ''` and `element.removeAttribute('aria-invalid')`) on subsequent validation attempts.
